# Convenciones frontend

- React funcional y TypeScript estricto.
- UI en español, responsive desde 375 px y navegable por teclado.
- Mantener el estilo táctil y alegre definido en #[[file:docs/04_UX_UI.md]].
- Estados de carga, vacío, error, bloqueo y éxito son obligatorios.
- No depender de imágenes o fuentes remotas para completar el flujo.
- No guardar claves correctas en estado, storage o código del navegador.
