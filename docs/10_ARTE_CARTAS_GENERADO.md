# Arte generado para las cartas

Las 24 ilustraciones se generaron individualmente y se exportaron como WebP de hasta 768 × 768 px, calidad 82. El atlas anterior se usó sólo como referencia general de estilo; nombres, rareza, poderes y cantidades se renderizan como HTML.

## Prompt base

> Create one square collectible card illustration for a children's educational adventure app. Polished cheerful 3D storybook rendering, rounded toy-like forms, rich depth, clean central composition, vibrant harmonious palette, consistent with the supplied reference atlas only as a broad visual style. No card border, no text, no letters, no numbers, no logo, no watermark. Full-bleed 1:1 art.

Referencia visual: `frontend/src/assets/generated/story-rewards-atlas.png`.
